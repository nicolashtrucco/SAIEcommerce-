# Cursor Rules - UX/UI & Frontend Standards

## Project Vision

This website represents a company specialized in:

* Robotics Programming
* Industrial Automation
* Industry 4.0
* Manufacturing Technologies

The visual experience must communicate:

* Trust
* Technical expertise
* Precision
* Reliability
* Professionalism

The website should feel like a modern engineering company, not a marketing website.

The website should feel modern, premium and engineered.

Avoid startup gimmicks and overly futuristic concepts.

---

# Brand Identity

Use only the official brand palette.

Primary Colors:

* White — #FFFFFF
* Orange — #FF9933
* Gray — #808080

Color Usage:

* White should dominate the interface.
* Orange should be used as the primary accent color.
* Gray should be used for supporting elements, secondary text and visual balance.

Orange must be used intentionally.

Avoid introducing additional accent colors.

The design should feel clean, technical and professional.

Recommended ratio:

* 80% White
* 15% Gray
* 5% Orange

---

# Typography

Use the following font as the only typography across the entire website:

```css
@import url('https://fonts.googleapis.com/css2?family=Roboto:ital,wght@0,100..900;1,100..900&display=swap');
```

Font Family:

* Roboto

Typography is one of the most important visual elements of the website.

Guidelines:

* Prioritize readability.
* Create strong visual hierarchy.
* Use concise headlines.
* Keep text easy to scan.
* Maintain consistency throughout the entire website.
* Use typography as a primary visual element.

Avoid:

* Decorative fonts
* Multiple font families
* Overly stylized typography
* Trend-driven typography choices

The typography should communicate:

* Engineering precision
* Professionalism
* Technical expertise
* Reliability

---

# Tailwind CSS

Tailwind CSS is the official design system for the project.

Guidelines:

* Maintain consistency in spacing, sizing and layouts.
* Reuse existing patterns whenever possible.
* Create reusable UI patterns.
* Maintain visual consistency across all pages.
* Use a predictable spacing system.
* Build cohesive interfaces.

Avoid:

* Inconsistent spacing
* Random sizing values
* Visual inconsistencies
* Different design approaches for similar components

The entire website should feel like a unified design system.

---

# User Experience Principles

Every section must answer a clear user question.

Users should immediately understand:

1. What the company does.
2. Who the company helps.
3. Why the company is different.
4. How to get in touch.

Reduce cognitive load whenever possible.

Clarity is more important than creativity.

---

# Design Principles

Prioritize:

* Simplicity
* Consistency
* Readability
* Visual hierarchy
* White space

Avoid:

* Visual clutter
* Unnecessary decoration
* Overly complex layouts
* Trend-driven design choices that hurt usability

Every visual element should serve a purpose.

---

# Components

Think in reusable systems.

Before creating a new component, evaluate whether an existing pattern can be reused.

Maintain consistency across:

* Buttons
* Cards
* Forms
* Navigation
* Sections
* Layout blocks

Avoid duplicated UI patterns.

The interface should feel cohesive throughout the entire website.

---

# Clean Frontend Standards

Prioritize:

* Clean code
* Reusability
* Scalability
* Maintainability
* Readability

Before creating new code, evaluate whether an existing component, pattern or structure can be reused.

Avoid:

* Duplicate code
* Duplicate components
* Repeated layouts
* Repeated UI patterns
* Inconsistent naming
* Overcomplicated solutions

Prefer solutions that are easy to understand and maintain over clever solutions.

Think in systems, not individual pages.

---

# Animations

Use GSAP for motion.

Animations should support communication.

Animations should never become the focus of the page.

Preferred animations:

* Fade in
* Fade up
* Reveal on scroll
* Soft hover interactions
* Subtle transitions

Avoid:

* Excessive motion
* Distracting effects
* Infinite animations
* Unnecessary visual spectacle

Motion should reinforce professionalism.

---

# Icons

Use Lucide icons.

Icons should improve understanding and navigation.

Avoid decorative icon usage.

Icons must support content.

---

# Layout

Use generous spacing.

Allow content to breathe.

Avoid overcrowded sections.

Maintain consistent spacing throughout the website.

Visual rhythm should feel intentional and balanced.

---

# Content Presentation

The company should be perceived as:

* Professional
* Experienced
* Technical
* Reliable

Avoid exaggerated marketing language.

Focus on clarity, expertise and measurable value.

---

# Quality Check

Before creating any page, section or component, verify:

* Does it improve user understanding?
* Does it follow the brand identity?
* Does it maintain consistency?
* Can it be reused?
* Is it easy to maintain?
* Does it improve the overall user experience?

If not, simplify and improve the solution.

---

# Final Principle

Before generating any page, section or component, prioritize:

1. User Experience
2. Readability
3. Consistency
4. Reusability
5. Maintainability
6. Performance

Never sacrifice these principles for visual effects or trends.
